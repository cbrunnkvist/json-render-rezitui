# 14 - Incident Arcade

**Use case**: Incident management game with AI SRE advisor.

**Demonstrates**: Multi-pane layout, state-driven AI triggers, contextual AI prompts based on selected incident, confirmed actions.

**To run**: `npm start` after setting `.env`. Select an incident from the left pane; the AI suggests actions in the right pane. Try "Restart Service" to see the confirmation dialog.
